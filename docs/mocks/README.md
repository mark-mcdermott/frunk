# Mocks

The redesign target — 31 screens plus the legal-page layout spec.

Committed as WebP (quality 90) so they travel with the repository: the originals are
43 MB of PNG in `frunk-proj/branding/mock/`, outside the repo and gitignored, which means
anything working from a clone — CI, a cloud agent, a new machine — cannot see them.
These are 2.7 MB and readable at full detail.

`docs/DESIGN.md` is the written translation: colour tokens sampled from these pixels,
typography, component rules. Read it alongside the images, not instead of them.

**Source of truth is still the PSD** (`frunk-proj/branding/mock/z_frunk-mocks.psd`) plus
the rough drafts in `z_rough/`. Neither is committed — the PSD alone is 17 MB and neither
is needed to implement.
